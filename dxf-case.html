Решение

Как работает процессор

Программа следит за папкой «Новые файлы» в фоне. Как только появляется DXF — автоматически запускается цепочка обработки.

1

Разделение на детали

Находит наибольший замкнутый контур — это деталь. Сохраняет каждую в отдельный файл вида (толщина)номер-индекс.dxf.

2

Поворот оптимальной стороной

Разворачивает деталь так, чтобы наибольшая прямая сторона стала горизонтальной — для правильной подачи на станок.

3

Расчёт и добавление припусков

Эквидистант 1.5 мм (2.0 мм для стекла ≥10 мм). Криволинейные стороны получают дополнительный припуск на обламывание = 3×толщина.

4

Генерация Excel для 1С

Автоматически создаёт таблицу: Д×Ш, толщина, площадь, периметр, число вырезов — готово для импорта в 1С.

5

Маршрутизация по папкам

Готовые файлы — в «Файлы в резку». Нестандартные случаи — в «Ручная обработка» с пояснением в лог-файле.
