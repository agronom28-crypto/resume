Интеграция заявок с CRM и Telegram

Заявки с сайта проверяются, создаются как карточки в CRM и дублируются ответственному менеджеру в Telegram.

Услуга: API и CRM-интеграции Обсудить похожую задачу

Проблема заказчика

Заявки с сайта попадали на почту и терялись среди другой переписки, а менеджер вручную создавал карточки в CRM с задержкой.

Задача

Автоматически создавать карточку в CRM по каждой заявке с сайта и уведомлять ответственного менеджера в Telegram.

Решение

Реализован промежуточный сервис на FastAPI, который принимает вебхук с формы, проверяет данные, создаёт карточку через REST API CRM и отправляет уведомление в Telegram.

Схема работы: Заявка с сайта → проверка данных → создание карточки в CRM → назначение ответственного → уведомление в Telegram → журнал события.

Python FastAPI REST API Bitrix24 API Telegram Bot API

Результат

Карточка в CRM появляется автоматически сразу после отправки формы, без ручного переноса данных.

Ограничения и особенности

Возможности интеграции ограничены методами, доступными в API конкретной CRM и её тарифном плане.
