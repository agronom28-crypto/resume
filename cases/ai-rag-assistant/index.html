AI/RAG-ассистент по базе знаний

FastAPI-сервис с векторным поиском (Qdrant/Chroma), который отвечает на вопросы по документам компании со ссылками на источники.

Услуга: AI-ассистенты и RAG-системы Обсудить похожую задачу

Проблема заказчика

Поиск ответа в объёмной документации занимает время у сотрудников, а типовые вопросы повторяются без единой точки ответа.

Задача

Собрать сервис, который ищет релевantные фрагменты в базе документов и формирует ответ со ссылкой на источник, а не выдуманный текст.

Решение

Реализован FastAPI-сервис с индексацией документов в векторной базе (Qdrant/Chroma) и обращением к языковой модели с ограничением ответа контекстом найденных фрагментов.

Схема работы: Документы → индексация в векторной базе → запрос пользователя → поиск релевантных фрагментов → ответ модели со ссылкой на источник.

Python FastAPI LangChain Qdrant Chroma OpenAI API

Результат

Рабочий прототип поиска по базе знаний с указанием источника каждого ответа.

Ограничения и особенности

Точность ответа зависит от качества и полноты загруженной базы документов; без документов ассистент не отвечает по теме, которой нет в базе.
