Realty Hunter — мониторинг объявлений недвижимости

Мультитенантный бот отслеживает новые объявления, убирает дубли и уведомляет пользователей в Telegram.

Услуга: Парсеры и мониторинг данных Обсудить похожую задачу

Проблема заказчика

Пользователи вручную проверяют площадки объявлений несколько раз в день, чтобы не пропустить новое предложение раньше конкурентов.

Задача

Автоматически отслеживать появление новых объявлений по заданным параметрам и присылать уведомление без дублей.

Решение

Разработан мультитенантный сервис на очередях задач с изоляцией данных пользователей, ролями доступа и биллингом на основе подписки.

Схема работы: Настройка параметров поиска → регулярная проверка источников → сравнение с уже найденными → уведомление в Telegram при новом объявлении.

Python Docker Compose очереди задач Telegram Bot API

Результат

Пользователь получает уведомление о новом объявлении без ручной проверки площадок.

Ограничения и особенности

Работа ограничена правилами и доступностью конкретных источников объявлений; не гарантируется покрытие всех площадок без отдельного анализа.
