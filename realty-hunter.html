Что умеет

Функции, которые уже работают в проекте

Основано на архитектуре ядра + адаптеров и текущем README проекта — без обещаний, только реализованный функционал.

01

Мониторинг новых объявлений в реальном времени

Модуль «Охотник» (realty_monitor_task) регулярно опрашивает источники и присылает уведомление в Telegram сразу после появления нового объявления, подходящего под заданные параметры.

АвитоЦИАНarq-очередь задач
02

Гибкий поиск по единому контракту фильтров

Единый модуль поиска нормализует тип сделки (продажа/аренда/посуточно), тип объекта, цену, площадь, метро, район, ключевые слова и тип продавца — и одинаково применяет их для обеих площадок.

03

Выгрузка в Excel по заданным параметрам

Команда экспорта запускает отдельную задачу в очереди, которая формирует файл и отправляет его клиенту — весь путь запроса помечен идентификатором клиента для отдельного учёта.

04

Управление через Telegram без веб-панели

Команды /run, /stop, /status, /history, /menu дают полный контроль над источниками мониторинга прямо в чате, включая FSM-меню для добавления и редактирования.

05

Мультитенантность — один бот, много клиентов

Каждый клиент (тенант) видит только свои источники и запуски; роли user/admin/superadmin разграничивают доступ, а строгая изоляция закрыта регрессионными тестами.

Как внедряется

От заявки до первого уведомления

Платформа развёртывается через Docker Compose и управляется полностью из Telegram — без необходимости в веб-интерфейсе для клиента.

1

Заявка и брифинг

Уточняем площадки, регионы и критерии поиска под ваш кейс.

2

Создание тенанта

Суперадмин создаёт изолированный тенант с лимитами вашего тарифа.

3

Подключение в Telegram

Вы пишете боту, вас привязывают к тенанту командой /invite.

4

Настройка источников

Через /menu задаются параметры поиска — цена, район, тип сделки.

5

Бот начинает присылать объявления и готовить выгрузки по расписанию.
